# Guia de Formatos para Instagram

## 1. Stories
Ocupam a tela inteira do celular, por isso utilizam a proporção vertical total.
- **Proporção:** 9:16
- **Resolução recomendada:** 1080 x 1920 px
- **Dica:** Mantenha textos e elementos importantes centralizados para evitar que sejam cobertos pela foto de perfil no topo ou pela barra de resposta na base.

## 2. Post (Feed)
Existem três formatos principais, mas o vertical é o que mais ocupa espaço na tela do usuário.
- **Quadrado (Square):** 1:1 (1080 x 1080 px)
- **Vertical (Retrato):** 4:5 (1080 x 1350 px) — **Este é o mais recomendado para maior engajamento.**
- **Horizontal (Paisagem):** 1.91:1 (1080 x 566 px)

## 3. Carrossel
O carrossel segue as mesmas regras dos posts estáticos, mas com um detalhe crucial:
- **Proporção:** 1:1 ou 4:5
- **Regra de Ouro:** Todas as imagens ou vídeos do carrossel devem seguir a proporção da primeira mídia selecionada. Se a primeira for 1:1, todas as outras serão cortadas nesse formato.

## 4. Reels
Assim como os Stories, os Reels são feitos para visualização vertical em tela cheia.
- **Proporção:** 9:16
- **Resolução recomendada:** 1080 x 1920 px
- **Corte no Feed:** Lembre-se que, na grade do seu perfil, o Reels é exibido em um corte de 1:1 (quadrado centralizado), e no feed principal ele aparece na proporção 4:5. Mantenha as informações principais na área central.

## Resumo dos Formatos

| Nome do Formato | Onde ele aparece? | Como ele funciona / Onde fica? |
| :--- | :--- | :--- |
| **Post Único** | Feed (Grade do Perfil) | É uma imagem única. Pode ser Quadrada (1:1) ou Vertical (4:5). É o post "comum". |
| **Carrossel** | Feed (Grade do Perfil) | São várias imagens em sequência (o usuário "arrasta" para o lado). Ótimo para tutoriais. |
| **Stories** | Topo do App (Círculos) | Imagens ou vídeos verticais (9:16) que ocupam a tela toda. Somem após 24 horas. |
| **Reels** | Aba Reels / Feed | Vídeos curtos verticais (9:16). É o formato que mais traz seguidores novos hoje. |
| **Capa de Reels** | Grade do Perfil | Uma imagem fixa que você coloca "por cima" do vídeo para o seu perfil ficar organizado. |
| **Highlights (Destaques)** | Perfil (Abaixo da Bio) | São as "bolinhas" onde você salva Stories importantes para que eles não sumam. |
| **Capa de Highlight** | Perfil (Dentro das bolinhas) | O ícone ou desenho que aparece na frente de cada bolinha de destaque. |
